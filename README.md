# HTML Nested Lists

## Explanation

This project demonstrates how to create ordered, unordered, and nested lists using HTML.

## Problem Statement

Create a webpage that displays categories and their subcategories using different types of HTML lists.

## Features

* Ordered list
* Unordered list
* Nested list
* Multiple levels of list items
* Simple HTML structure

## How It Works

The `<ul>` element creates an unordered list.

The `<ol>` element creates an ordered list.

The `<li>` element defines an individual list item.

A list can be placed inside another list item to create a nested list.

## Technologies Used

* HTML5

## Program Flow

1. Open the webpage.
2. Display the main heading.
3. Display an unordered list of subjects.
4. Add nested topics under each subject.
5. Display an ordered list of steps.
